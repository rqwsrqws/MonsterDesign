# Monster-Lead spider demo

Тестовая hero-секция: кибер-паук забирается на логотип Telegram. Компонент можно перенести в основной сайт.

## Запуск

```bash
npm install
npm run dev
```

Открой локальный URL из терминала.

## Что вставлять в сайт

- `src/components/Hero.jsx` — вся секция
- `src/components/ClimbingSpider.jsx` — SVG-паук
- `src/components/TelegramSpiderMark.jsx` — логотип Telegram
- `src/components/Hero.css` — стили и анимация `climb-on-logo`

Кнопка **Повторить анимацию** перезапускает забег паука.
